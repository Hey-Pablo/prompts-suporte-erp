# Ativar uma conta de usuário no ERP

## Objetivo

Ativar uma conta de usuário e confirmar a ativação com um teste de acesso.

## Pré-requisitos

Os dados fornecidos não especificam as permissões necessárias nem como identificar a conta correta.

## Passos

1. No menu **Usuários**, selecione a conta.
2. Marque a opção **Ativo**.

## Verificação

Faça um teste de acesso com a conta selecionada. Se o acesso funcionar, a ativação está confirmada.

## Lacunas

O procedimento não informa se é necessário salvar ou confirmar a alteração, como executar o teste de acesso ou o que fazer se ele falhar.
